# 逐行讲解

这份讲解对应当前项目里的手写源代码。每个文件按原始行号列出，左侧代码可与编辑器逐行对照。先阅读 [架构与接口](./架构与接口.md)，再按入口、公共模块、页面、后端、SQL、脚本的顺序阅读。

JavaScript 中的 ref 通过 `.value` 读写，模板会自动解包；数据库里的商品才是正式数据，表单草稿尚未保存。前端检查改善使用体验，后端检查保证请求合法，数据库约束是最后一层保护。

## 如何跟着代码走一遍

1. 从 index.html 找到 main.js，再找到 App.vue 与路由/页面。
2. 找到登录表单的 submit 事件，沿 API 请求进入后端控制器。
3. 再看商品列表的查询参数、数据库查询、返回 JSON 与模板循环。
4. 看新增/编辑时表单草稿如何组装为请求，后端如何检查并落库。
5. 最后看订单事务：商品价格快照、扣库存、状态流转、取消归还库存。
